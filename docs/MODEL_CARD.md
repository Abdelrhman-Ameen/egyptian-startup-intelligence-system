# Model card

## Intended use

Financial research demonstration on historical Polish statements. The UI evaluates saved historical cases using outer-fold models that excluded each case from fitting, tuning and calibration. A general research-input endpoint also exists, with unverified training membership explicitly reported. No Egyptian startup bankruptcy prediction has been validated.

## Candidates and architecture

- Training-prevalence reference, learned only on the corresponding training fold.
- Regularized logistic regression with signed-log, median imputation and scaling.
- Histogram gradient boosting with train-fold median imputation.
- PyTorch residual MLP: input projection to 64 units; two pre-normalized residual blocks, each LayerNorm → Linear → GELU → Dropout → Linear; one output logit. BCEWithLogitsLoss and AdamW. Early stopping selects epochs on a group-separated internal validation subset; the estimator then refits the epoch count on its supplied training rows.

PyTorch training exports weights for deterministic NumPy/SciPy inference. Every neural fit checks its export against PyTorch; the serving image does not need Torch. This reduces CPU-serving memory and image size without dropping the neural experiment.

## Evaluation

Protocol: `configs/experiment.json`. Five outer, three inner stratified group folds. Exact-vector groups stay together. All preprocessing, candidate selection and calibration occur within outer training. Four configurations per family/schema include weighted and unweighted alternatives. Family selection uses mean inner-fold average precision. The outer-fold nested-selection row evaluates that selection procedure; individual-family rows are reported too. Full-data release fitting is separate and has no independent test metric.

Sigmoid calibration is fit from inner out-of-fold scores; a cross-fitted inner Brier comparison decides whether to retain it. That comparison is an internal selection diagnostic, not a separate unbiased estimate. Final outer predictions assess the complete procedure.

Primary metric: average precision. Also report ROC-AUC, Brier, log loss and recall/precision when reviewing the top 10% within each held-out fold. Boundary score ties receive expected credit under uniform selection within the tied group, avoiding dependence on source row order. Metrics are means and sample standard deviations across folds; these SDs are not confidence intervals. The top-decile task is a benchmark review-budget illustration, not an operational lending decision.

Experiments include 13/64 ratios, missingness-only inputs, and 64 ratios without explicit masks. Median imputation can preserve traces of missingness; removing mask columns does not isolate a purely financial or causal signal. Complete-case subgroups and accounting checks do not prove transportability.

Additional neural seed sensitivity uses fixed architecture/configuration and reports all seeds. No best seed is selected for the headline metric.

## Explanations and input policy

Global held-out permutation relevance is displayed with the current case's observed values. It is not local attribution. Correlated ratios can share importance; perturbations are descriptive model diagnostics, not feasible financial interventions or causal effects.

Research inputs require at least 75% of schema fields. This is a product input policy, not an empirically validated confidence gate. Central-99% source-range flags are diagnostics, not proof of in/out-of-distribution status. Scores are not labeled confidence.

## Limitations

Historical selection, prior exploratory analysis, source-specific missingness, missing company/time keys and unresolved accounting definitions constrain interpretation. There is no independent Egyptian startup cohort, temporal backtest or prospective validation. Calibration within this source does not establish calibrated probabilities elsewhere. The cash-flow engine is conditional accounting and does not translate scenarios into changes in bankruptcy probability.
